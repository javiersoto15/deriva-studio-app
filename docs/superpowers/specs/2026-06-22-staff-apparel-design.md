# Deriva Staff Apparel — Tee + Hoodie Design Spec

**Date:** 2026-06-22
**Status:** Approved direction, pending spec review
**Surface type:** Physical merch / staff uniform (Paper artboards → print-ready PDFs, like coffee bags & stickers)
**Edition:** Vol. 001 (first apparel run)

---

## 1. Intent

Two-piece staff uniform — a t-shirt and a pullover hoodie — that reads **minimalist but powerful**. The strategy is borrowed from AllSaints' apparel economy (and the near-universal specialty-coffee convention): an **almost-empty front with one small mark, one commanding back statement**, plus two quiet "edition" details (nape + sleeve) that reward a closer look. The visual fingerprint stays unmistakably Deriva's editorial-chapbook language; only the *attitude* and *placement* come from AllSaints.

Chosen creative blend: **grunge-editorial hybrid** — washed/garment-dyed bodies, faded ink, lightly eroded display edges, tonal texture from the dye itself. No gradients, glows, or vignettes (brandbook rule); all "warmth" comes from wash + ink hand + type + space.

## 2. Locked decisions

| Decision | Choice |
|---|---|
| Direction | Grunge-editorial hybrid (AllSaints placement + Deriva chapbook type) |
| Colorway | Tee = washed **Faded Bone**; Hoodie = washed **Faded Black** |
| Back hero | **Wordmark identity** (ĐERIVA + COFFEE STUDIO + location/year + colophon seal) |
| Deliverable | **Design boards in Paper** (front / back / sleeve+nape flats per garment), then export print-ready PDFs |
| Hoodie front | Pullover with **kangaroo pocket**, chest mark above pocket line |
| Production | **All screen print**, 2 spot colors (discharge / water-based for soft hand) |
| Green moment | `#00311F` exactly **once per garment** — on the back colophon-seal isotipo |

## 3. Placement architecture (both garments)

The AllSaints economy — one statement per zone:

| Zone | Content | Spec |
|---|---|---|
| **Front — left chest** | Isotipo + small `ĐERIVA` lockup | ~9 cm wide; 4–6" down from shoulder seam, ~9 cm in from center; screen print, ink only |
| **Back — hero** | `ĐERIVA` / rule / `COFFEE STUDIO` / `SANTIAGO · EST·MMXXVI` / colophon seal | 28–30 cm wide; top edge ~7.6 cm below collar; 2-color screen print |
| **Nape (back-neck)** | `§ Vol. 001` (or tiny isotipo) | ≤7.6 cm wide; just below collar; ink only |
| **Right sleeve** | `№ 001` set vertical | max 7.6 cm; IBM Plex Mono; ink only |

## 4. Type, color, treatment

**Typography (all screen print — fine type cannot be embroidered):**
- `ĐERIVA` wordmark — **Baskerville** (the LogoLockup wordmark face); back hero set large; the only display use.
- `COFFEE STUDIO` / `SANTIAGO · EST·MMXXVI` — **Poppins SemiBold**, tracked uppercase (label voice). Year in Roman numerals (`MMXXVI`) = the AllSaints establishment-mark borrow.
- `№ 001` / `§ Vol. 001` — **IBM Plex Mono** (technical-type signature).

**Color (2 spot colors per garment):**
- Tee (Faded Bone ground): **faded ink-black** print + **#00311F green** on the back seal only.
- Hoodie (Faded Black ground): **bone/plaster** print + **#00311F green** on the back seal only.

**Grunge-editorial treatment:** subtle **erosion/distress** on the back wordmark + EST mark edges (letterpress-that-didn't-fully-ink), plus inherent garment-dye mottling. Front chest mark stays cleaner (premium read). No digital gradients.

## 5. Garment & production

- **Blanks:** AS Colour *Heavy Faded Tee 5082* — **Faded Bone** (tee) + **Faded Black** (hoodie). Heavyweight (7.1 oz), garment-dyed, lived-in. (Alt: Comfort Colors 1717 Bone.)
- **Ink:** discharge or water-based for soft, "printed-but-feels-unprinted" hand; tone sits in the fiber.
- **Colors per screen:** 2 max (ink + green) → cheapest screen-print zone, on the single-green-moment rule.
- **Hoodie:** pullover, kangaroo pocket; chest mark above pocket.

## 6. Paper artboard structure

On the **Print & Collateral** page (per `reference_paper_file_organization.md`), six artboards as two garment sheets:

- **Tee sheet:** front flat · back flat · sleeve+nape detail — each with dimension callouts, type specs, color chips.
- **Hoodie sheet:** front flat (chest mark above pocket) · back flat · sleeve+nape detail — same callouts.

Boards are reviewable flats (coffee-bag-board style). After look approval → export print-ready trazado PDFs at exact cm into a new `09_marketing/apparel/` folder.

## 7. Out of scope (YAGNI)

- Realistic worn-garment mockups (can add later if needed for sign-off).
- Aprons, caps, leather patches, additional colorways.
- Embroidery setup (chosen all-screen-print).
- Multiple editions / seasonal variants (this is Vol. 001 only).

## 8. Success criteria

- Reads "minimalist but powerful" — empty front, one commanding back, at bar distance.
- Unmistakably Deriva: chapbook type, single green moment, edition numbering, colophon seal.
- Production-feasible as specced: 2-color screen print, standard placements, named blank.
- Passes the publication test: sits alongside placemat/app/email/brochure as one publication.
